## 1. Модули 🔄 (параллельно)

- 🔄 Загрузка данных: CSV / JSON / XLSX / папки картинок / HTML / списки URL, автоопределение колонок + синтетический датасет с метками + метрики качества
- 🔄 Текст: OCR скриншотов, IOC (телефоны, e-mail, крипто-кошельки, Telegram/WhatsApp, IBAN), персоны и бренды (справочник + LLM), нарратив, обещание, CTA, MinHash
- 🔄 Изображения: pHash/dHash/wHash/colorHash, цвета, лица (YuNet + SFace) и сопоставление с базой лиц
- 🔄 Инфраструктура: цепочка редиректов, HTML (трекеры GA/GTM/Pixel, формы, шаблон DOM), favicon hash, DNS, RDAP/WHOIS, IP/ASN, TLS, crt.sh; кэш и офлайн-режим
- 🔄 Связи: доказательства с весами, ослабление частых признаков (общий CDN ≠ одна кампания), кандидаты (LSH), кластеризация в кампании, сводки, разбор нового материала
- 🔄 Пайплайн + CLI + экспорт Neo4j/GraphML + Docker + `start.sh` / `start.bat`
- 🔄 Интерфейс Streamlit: обзор, кампании, граф, карточка материала, анализ нового материала, методика
